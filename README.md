# ECHO-FINANCE

ECHO-FINANCE is a web application built with React, Redux Toolkit, and Vite. It provides financial insights and predictions using various charts and data visualizations.

## Features

- Dashboard with financial KPIs
- Product listings
- Transaction history
- Revenue predictions using regression analysis

## Technologies Used

- React
- Redux Toolkit
- Vite
- Material-UI
- Recharts
- MongoDB (for backend data storage)
